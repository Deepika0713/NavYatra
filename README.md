# 🧭 NavYatra – AI-Powered Smart Tourist Trip Planner

> **Plan smarter. Travel better. Explore Incredible India with confidence.**

NavYatra is a modern web application that helps travelers discover, organize, and optimize trips to famous tourist destinations across India. It combines location-based discovery, intelligent itinerary planning, travel estimation, and an elegant user experience inspired by Shopify Editions.

The project focuses on reducing travel planning effort by automatically suggesting nearby attractions, estimating travel and visit durations, calculating approximate costs, and generating a structured itinerary.

---

* 📍 Detect current location or select a destination manually

# 🚀 Application Workflow

### 1. Landing Page

The user begins by opening NavYatra and selecting or allowing access to their location.

### 2. Explore Places

Nearby tourist attractions are presented as visually appealing cards with essential travel information.

### 3. Trip Planning

The user selects one or more destinations and specifies the preferred travel date and starting time.

### 4. Smart Itinerary

The system estimates:

* Travel duration
* Visit duration
* Route sequence
* Total estimated time
* Approximate travel expenses

### 5. Dashboard

A complete summary of the planned trip is presented, helping the user make informed travel decisions.
